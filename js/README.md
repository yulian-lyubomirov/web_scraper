# JavaScript playground

This folder is a small JavaScript learning area alongside the original Python project.
It uses Node.js and has no additional package dependencies.

## Try it with Quokka.js

1. Open `playground.js` in VS Code.
2. Open the Command Palette with `Ctrl+Shift+P`.
3. Run **Quokka.js: Start on Current File**.
4. Change `maxPrice` or the example listings and see the results update inline.

You can also run the file from a terminal:

```powershell
cd C:\projects\web_scraping\web_scraper\js
npm start
```

The listing data is mock data, included only to practice JavaScript arrays,
objects, `filter`, `map`, and `reduce`. Idealista's terms require express written
permission for automated collection. Use the official API after access is granted;
do not use this example to retry the blocked website.
